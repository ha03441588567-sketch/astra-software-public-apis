# Contributing

Thanks for wanting to contribute! Please follow these rules:

1. **One API per Pull Request.**
2. Add your entry in **alphabetical order** within the correct category.
3. Use this table row format:
   ```
   | [API Name](https://link-to-docs) | Short description | Auth type (No / apiKey / OAuth / X-Mashape-Key) | Yes/No |
   ```
4. Make sure the link works and points to official documentation.
5. If your API needs a new category, add it to the Table of Contents too.
6. Run a markdown linter before submitting (no broken tables, no trailing whitespace).
7. Keep descriptions under 100 characters.

## Checklist before submitting a PR
- [ ] Added in alphabetical order
- [ ] Correct category
- [ ] Working HTTPS link
- [ ] Auth column filled correctly
- [ ] Table of Contents updated (if new category)
